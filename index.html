Panduan Deploy ke Vercel

Publikasikan aplikasi web ini secara gratis dalam 2 menit

  1. Simpan berkas index.html ini ke dalam folder di komputer Anda.
  2. Upload folder tersebut ke akun GitHub Anda (buat repository baru).
  3. Buka dashboard Vercel.com dan buat New Project.
  4. Pilih repository GitHub tersebut, lalu klik tombol Deploy.
  5. Selesai! Web aplikasi Anda sudah online dengan domain custom gratis dari Vercel.
Tips Supabase: Saat sudah ter-deploy di Vercel, cukup buka modal Supabase di web live Anda dan masukkan credentials URL/Key. Data akan tersinkron otomatis untuk semua anggota tim!
